# Captures d'écran du README

Images référencées par la section « Aperçu et design » du [README racine](../../README.md).

| Fichier | Usage |
|---|---|
| `Opportune.png` | Logo + baseline, hero en tête du README (thème clair, fond transparent) |
| `Opportune-dark.png` | Même hero pour le thème sombre de GitHub |
| `WelcomeScreen.png` | Écran d'accueil « Démo / Mon espace » |
| `guide.png` | Cockpit — guide « Nouveau profil » en 3 étapes |
| `accueil.png` | Cockpit — synthèse (compteurs, activité récente) |
| `profil.png` | Profil — import CV, compétences, parcours |
| `offres.png` | Catalogue d'offres scorées |
| `recommandation.png` | Fiche recommandation + lettre + validation |
| `reglages.png` | Réglages : clés Adzuna, flux RSS, entreprises ciblées |

Toutes les captures sont prises depuis l'espace **Démo** (aucune donnée personnelle), dans les
mêmes conditions : fenêtre 1440×900 rendue en x2 (2880×1800), thème clair, police Segoe UI,
démo restaurée juste avant (« Restaurer l'exemple ») et assistant local joignable (pas de bandeau
d'erreur). `guide.png` montre une recherche neuve créée pour l'occasion.

La vidéo de démo n'est pas dans le dépôt : elle est hébergée par GitHub (déposée dans la PR #219)
et lue directement dans le README.
